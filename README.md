Retail Data Analysis project:

    Ce projet vise à analyser des données de transactions e-commerce a fin d'evaluer la qualité des données, d'explorer les corportement d'achat et d'identifier des insights business actionnables

Dataset :

    Source :
        -Type: CSV
        -Nombre de lignes : 541909 lignes
        -Nombre de columns : 8columns

    Description des variables:
        Colonne:             Description:
        InvoiceNo           Identifiant de facture
        StockCode           Code de produit
        Description         Description du produit
        Quantity            Quantite achetée
        InvoiceDate         Date achetée
        UnitPrice           prix unitaire
        CustomerId          Identifiant Client
        Country             Pays

Méthodologie:
    1. Importation et inspection des données (EDA niveau1)
    2. Audit qualité (valeurs manquantes,doublons, outliers)
    3. Nettoyage et préparation des données
    4. Feature Engineering
    5. Analyse Exploratoire et Visualisation
    6.Modelisation
    7.synthese des insights
